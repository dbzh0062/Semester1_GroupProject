

# User Stories 

## 1
As a lecturer with other commitments (research, admin)
I want to be able to find my lecture theatres easily
So that I can focus on other things and not waste time looking for lecture theatres.
### Acceptance criteria
Given all the buildings are shown on the map
When i click on a specific building
then directions to all the rooms is shown

Given my location services are active
When i open the map
then my location is highlighted on the map

## 2
As a lecturer with many students
I want to be able to give them information and ensure they will reliably see it
So that I can be confident students are up to date with important information
### Acceptance criteria
Given I want to make an announcement
When i click the button
then should be able to write in text box and attach files

Given i want to make an announcment to a specific group
When i click the button
I should be able to pick specific tutor groups/lecture groups/students

## 3
As an older person with limited tech skills
I want the system to be clear and intuitive
So that I can focus on my course and not figuring out how to use the system
### Acceptance criteria
Given i want to navigate to the map
when i open the app
I should be able to navigate to it in no more than 2 taps
